## 🔮 AI Prediction Features

### How It Works

1. Load any symbol (AAPL, BTCUSD, EURUSD)
2. Click **🔮 AI Predict** button
3. Claude Sonnet 4.5 analyzes data
4. Predictions appear as semi-transparent candles
5. Orange border distinguishes predictions
6. Vertical line separates real from predicted

### Visual Appearance

```
[Real Candles - Solid] | [Predicted Candles - Transparent]
      Green/Red        |    Semi-transparent + Orange border
         ↓             |              ↓
    [Separator Line - Orange Dashed]
```
